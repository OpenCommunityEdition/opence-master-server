Disputed listings

A host's listing is published by one publisher at a time. A publish whose listing's host key another publisher's live server holds is refused (listing_taken): the holder may have copied the listing from a list while the host's own publisher was not publishing. A holder whose listing is not renewed for 90 seconds loses the host key to a publisher with a newer listing of it; one that keeps copying fresh listings does not. To settle a dispute, hide the copying server above, or suspend its publisher: neither then holds the host key, and the host's own publisher's next publish is taken. The last 7 days, refusals once an hour per server and holder.
